# Cafe Manager Android App

A Flutter starter for a restaurant/cafe management system using ETB.

## Current prototype
- Dashboard
- Daily sales/purchase/expense/profit cards
- Restaurant table grid
- Table-based POS
- Menu item selection
- ETB totals
- Navigation for planned modules

## Planned production modules
- SQLite offline database
- Products and ingredient recipes
- Purchases and suppliers
- Inventory and automatic stock deduction
- Waste/stock adjustments
- Expenses
- Daily/weekly/monthly profit and loss
- Employee accounts and permissions
- Kitchen order status
- Receipts
- Reports and PDF/Excel export
- Backup/synchronization API

## Run
Install Flutter, then:

flutter pub get
flutter run

For an Android APK:
flutter build apk --release
